## Overview

**Voyara Journeys** is a flagship editorial travel agency website tailored for discerning travelers, couples, and multi-generational families. Designed with an obsidian and champagne gold aesthetic, the platform features bespoke private curations, interactive dossiers, live WhatsApp concierge integration, and full DPDP/GDPR-compliant travel inquiry workflows.

---

## Key Features

- **Editorial Luxury Showcase**: High-performance obsidian dark palette with fluid typography and interactive custom cursor.
- **Curated Private Itineraries**: Dedicated static showcases and detail routes (`/packages/[slug]`) for Kashmir Heli-ski, Swiss Alps Chalets, Maldives Overwater Villas, and Royal Rajasthan Palaces.
- **Interactive Dossier Inquiry**: Modal-driven trip planning workflows with destination picker, budget tiers, and direct WhatsApp concierge handoff.
- **Accredited Trust Strip**: Transparent licensing details (IATA, Ministry of Tourism, TAAI, GSTIN) and traveler security assurances.
- **Search Engine Optimization**: Dynamic JSON-LD structured data (`EditorialJsonLd`), OpenGraph tags, sitemap, and robots.txt.

## Getting Started

### Prerequisites
- Node.js 20 or higher
- npm

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
npm run start
```
